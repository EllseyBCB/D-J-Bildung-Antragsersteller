Creator-Links erstellen

Gib den Namen eines YouTubers / Influencers ein. Du bekommst einen eigenen Link – jeder Aufruf, jede ausgefüllte Bewerbung und jeder abgeschickte Antrag wird im Google-Sheet diesem Creator zugeordnet.

Wo sehe ich die Ergebnisse?

Im Google-Sheet „D+J – Arbeit 4.0 Leads":

  • Blatt „Auswertung": je Creator eine Zeile mit Klicks → Besucher → Ausgefüllt → Antrag erstellt → Abgeschickt → Bildungsgutscheine.
  • Blatt „Leads": jeder einzelne Antrag mit dem Creator-Namen in der Spalte „Creator".

Tipp: Diese Seite ist nur für euch intern – setz sie dir als Lesezeichen. Ein Link funktioniert auch von Hand: einfach ?ref=name an die Landingpage-Adresse anhängen.
